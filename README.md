# Electronics Sales Analysis Dashboard

## Project Overview
An interactive sales dashboard developed using Microsoft Power BI to analyze electronics sales data.

## Tools Used
- Microsoft Power BI
- Power Query
- Excel

## Dashboard Features
- Total sales analysis
- Product-wise sales performance
- Payment method analysis
- Customer gender analysis
- Sales trends
- Interactive visualizations

## Objective
To analyze electronics sales data and generate meaningful business insights through interactive visualizations.
